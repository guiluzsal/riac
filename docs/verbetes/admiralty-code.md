# Admiralty Code

**Definição:** sistema de duas letras/números para avaliar, de forma
independente, a confiabilidade de uma fonte (A–F) e a credibilidade de uma
informação específica (1–6).

!!! info "Origem"
    Desenvolvido pelo Almirantado britânico (Admiralty) durante a Segunda
    Guerra Mundial, para avaliar rapidamente relatos vindos de navios,
    agentes e serviços aliados. Posteriormente formalizado pela OTAN como
    NATO System, codificado na doutrina AJP-2.1 (STANAG 2191).

## Explicação

A **confiabilidade da fonte** é avaliada de A (completamente confiável) a
E (não confiável), com F para "não é possível julgar" — baseada na
capacidade técnica da fonte ou, para fontes humanas, em seu histórico. A
**credibilidade da informação** é avaliada de 1 (confirmada por outras
fontes) a 5 (improvável), com 6 para "não é possível julgar" — baseada em
corroboração, independentemente da reputação da fonte. Uma fonte
historicamente confiável (A) ainda pode entregar uma informação pontual
duvidosa (4), por exemplo.

## Exemplo prático

Um analista recebe de uma fonte humana nova, ainda sem histórico (F), uma
informação que já foi corroborada por telemetria interna (1). O relato é
classificado como F1: fonte cuja confiabilidade ainda não pode ser
julgada, mas informação confirmada por outra fonte.

## Relação com outros modelos (ATT&CK, Diamond Model, Kill Chain…)

O Admiralty Code é usado na fase de processamento do ciclo de
inteligência, de forma complementar ao [TLP](traffic-light-protocol.md) e
ao [PAP](permissible-actions-protocol.md), que tratam de compartilhamento
e ação, não de confiabilidade da fonte.
